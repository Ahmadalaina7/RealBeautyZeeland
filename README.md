# Real Beauty Zeeland

Website voor schoonheidssalon Real Beauty Zeeland in Vlissingen.

## Lokaal bekijken

```bash
python -m http.server 8080
```

Open daarna http://localhost:8080/

## Structuur

- `index.html` — home
- `behandelingen.html` — overzicht + tarieven
- `behandelingen/` — detailpagina's
- `contact.html` — afspraakformulier
- `css/style.css` — styling
- `js/main.js` — navigatie en interactie
